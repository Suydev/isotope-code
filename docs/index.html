Run the study app on your own device.

IsotopeAI Local is downloadable software: a local server, a browser app, offline-friendly study tools, and Supabase cloud sync for community, events, auth, storage, and realtime.

Local first

Starts on your computer or phone. No VPS needed. Open localhost and study.

Cloud synced

Supabase powers auth, onboarding, community, events, storage, and realtime when online.

Offline tolerant

Local study flows keep working; cloud widgets degrade cleanly instead of crashing.

Owner tools

Private admin mode for diagnostics, SQL patching, event management, and verification.

Install in one command

# macOS, Linux, Termux
chmod +x setup.sh
./setup.sh
:: Windows
setup.bat

:: PowerShell
./install.ps1

How it works

Download

Clone or unzip the GitHub release.

Run setup

The script detects your platform, checks Node/Git, creates .env, and starts the server.

Open localhost

The app runs locally while Supabase syncs shared data online.

Not a hosting site

Do not deploy this as one central web backend for everyone. The intended model is many local installs worldwide connected to the Isotope Supabase cloud with RLS, auth, storage, and realtime.
