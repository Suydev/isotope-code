✅ Cloud sync fixed

Login on a new device now correctly downloads your cloud backup and applies it. Two root-cause bugs patched: missing cloud_snapshot field and a timing race with the startup sync.

✅ Storage cleanup

Old timestamped backup files in Supabase Storage are now automatically pruned after each upload. Only the 3 most recent exports and 5 snapshot history files are kept.

Local server

Run node server.mjs or isotope start from the project folder, then open localhost:3000 in any browser.

Cross-device sync

Your study data (tasks, sessions, subjects, habits, stats) is backed up to Supabase Storage and automatically restored when you log in on a new device.

Offline shell

The service worker caches the app shell after first launch and shows honest offline status without crashing.

One-tap install

bash setup.sh installs Node.js 22 via NodeSource on Ubuntu/Debian, sets up global isotope command, and starts the server.

Install

# macOS / Linux / Termux
git clone https://github.com/Suydev/isotope-code.git
cd isotope-code
cp .env.example .env   # fill in Supabase URL + anon key
bash setup.sh
:: Windows (PowerShell)
git clone https://github.com/Suydev/isotope-code.git
cd isotope-code
copy .env.example .env  & REM fill in Supabase keys
.\install.ps1

After setup, open http://localhost:3000 — sign in with your Supabase account and your cloud data syncs automatically.

Global commands

isotope start, isotope stop, isotope restart, isotope update, isotope status, isotope doctor, isotope open, and isotope logs — work from any directory after setup.

Termux / Android

Run bash setup.sh in Termux. Optionally run bash setup-termux-widget.sh for home-screen shortcuts: isotope-start, isotope-update, isotope-open.

Supabase setup

Create a free project at supabase.com, run the SQL from the README, and paste your project URL + anon key into .env.

📖 Docs badge in app

A floating 📖 Docs badge links to this page from every screen in the app — including the login page — so first-time users can find setup instructions instantly.

Supabase is not the website host

Do not try to access the app at https://<project-ref>.supabase.co/. That URL is for Supabase APIs only. Isotope runs entirely through your local Node server at localhost:3000. Supabase is used for auth, database, storage, realtime, and community sync — not as a web host.
