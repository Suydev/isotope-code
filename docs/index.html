🚀 Quick Start

git clone https://github.com/Suydev/isotope-code.git
cd isotope-code
cp .env.example .env
# Fill in your Supabase credentials in .env
PORT=5000 node server.mjs

Then visit /__admin/patch once to apply the database schema.

🔒 Security Notes

TopicNotes
SecretsNever commit .env. All keys via env vars. Server hard-fails if keys are missing.
Admin routesDisabled unless ENABLE_ADMIN_MODE=true, ADMIN_SECRET, and SUPABASE_SERVICE_ROLE_KEY are set.
service_role keyServer-only. Browser bundles receive only the configured anon key.
RLS PoliciesEvery table has RLS. group_* tables use _is_group_member() SECURITY DEFINER to prevent recursion.
