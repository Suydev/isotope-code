Run Isotope on your own device.

Isotope is downloadable local-server software. Supabase provides auth, database, storage, realtime, and community sync, but the user-facing app runs through your local Node server.

Download releaseView source

Local server

Run node server.mjs or isotope start, then open localhost.

Cloud sync

Supabase powers online auth, profiles, community groups, storage, and realtime.

Offline shell

The service worker caches the app shell after first launch and shows honest offline status.

Command updates

The update banner shows isotope update. It never stops the server from the browser.

Install

# macOS, Linux, Termux
bash setup.sh
:: Windows
setup.bat

:: PowerShell
.\install.ps1

Global commands

isotope start, isotope stop, isotope restart, isotope update, isotope status, isotope doctor, isotope open, and isotope logs work from any directory after setup.

Termux Widget

Run bash setup-termux-widget.sh, then add Android home-screen shortcuts such as isotope-start, isotope-update, isotope-open, and isotope-doctor.

Supabase is not the website host

Do not try to host the app at https://<project-ref>.supabase.co/. That URL is for Supabase APIs and services. Isotope is intended as many local installs connected to Supabase cloud sync with RLS, auth, storage, and realtime.
