Run your study system on your own device.

Install IsotopeAI on Android, Windows, macOS, or Linux. Use Supabase when you want login, backup, restore, and community features.

Install now Download ZIP

Safe sync rule

If this device is empty and cloud has study data, IsotopeAI blocks upload and restores cloud first.

BLOCKED_EMPTY_OVERWRITE

This protects tasks, sessions, subjects, habits, exams, tests, and mock tests.

Install

Android

Use Termux from F-Droid or GitHub.

bash <(curl -fsSL https://raw.githubusercontent.com/Suydev/isotope-code/main/install-termux.sh)

Linux

Clone, set up, start.

git clone https://github.com/Suydev/isotope-code.git
cd isotope-code
bash setup.sh
isotope start

macOS

Install Git and Node.js first.

git clone https://github.com/Suydev/isotope-code.git
cd isotope-code
bash setup.sh
isotope start

Windows

Use PowerShell.

git clone https://github.com/Suydev/isotope-code.git
cd isotope-code
.\install.ps1

Open the app

After setup, start the server and open the local address.

isotope start
http://127.0.0.1:3000

Fix problems

These commands work after setup.

isotope doctor
isotope logs
isotope repair
isotope update

Supabase

Use Supabase for cloud features

Create a free Supabase project. Run isotope-complete.sql in SQL Editor. Put the project URL and anon key in .env.

SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_ANON_KEY=your-anon-public-key

Do not leak secrets

Never commit .env. Never put the service-role key in frontend code. Use service-role only on your own server for admin repair.

Backup paths

Main backup, history, and mirror paths:

{userId}/backups/latest.json
{userId}/backups/history/{timestamp}-{hash}.json
{userId}/cloud-snapshot/latest.json

Old import/export folders are still read so old users can restore safely.
