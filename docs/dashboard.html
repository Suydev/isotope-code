    Tasks

    Add one, then complete it. A completed task is struck through, marked, and announced — none of which depends on colour.

    Press Enter or the Add task button to create the task.

      Where it is stored

      Tasks are local-first: written to IndexedDB, and replicated to the user-content backup rather than row-synced. The tasks row carries the session it was completed in.

      Real columns: status, priority, subject, completed_at, completed_in_session.

      Loaded chunks

      The bundle files behind the app's routes, in the order the router resolves them. Each is lazy — nothing here is in the entry chunk.
